# מטלה ראשונה - הבנת השפה C++ ועקרונותיה הבסיסיים

## יושרה אקדמית

במהלך העבודה על המטלות, מותר להתייעץ עם סטודנטים אחרים ולחפש מידע באינטרנט. עם זאת, חל איסור להעתיק קטעי קוד שלמים ממקורות חיצוניים, כולל סטודנטים אחרים, אתרי אינטרנט ומודלי בינה מלאכותית (כגון ChatGPT).

יש לדווח על כל עזרה שקיבלתם, בין אם מדובר בהתייעצות עם סטודנטים אחרים או במידע שנמצא באינטרנט, בהתאם ל[תקנון היושר של המחלקה](https://www.ariel.ac.il/wp/cs/wp-content/uploads/sites/88/2020/08/Guidelines-for-Academic-Integrity.pdf).
**במקרה של שימוש בכלי בינה מלאכותית (AI), יש לצרף את הפרומפטים שהוזנו ואת התשובות שהתקבלו**.


## הקדמה
מטלה זו היא חלק מהקורס "C++ תכנות מתקדם" ומטרתה להדגים את היתרונות והתכונות המיוחדות של שפת C++ בהשוואה לשפות תכנות אחרות כגון C ו-Java. המטלה מתמקדת ביישום של מחלקות פשוטות לייצוג צורות גיאומטריות ופונקציות שונות המדגישות את הפיצ'רים הייחודיים של C++.

## מבנה המטלה
במטלה זו תתבקשו להשלים קוד חסר במספר קבצים שמממשים מחלקות ופונקציות שונות. הקבצים מתארים מחלקות גיאומטריות בסיסיות (נקודה ומעגל) וכן פונקציות עזר שמדגימות את היתרונות של C++.

## דרישות והנחיות
- להשלים את הקוד החסר בקבצים שסופקו
- לוודא שהקוד מתקמפל ופועל ללא שגיאות
- להדגים את היכולות והיתרונות הייחודיים של שפת C++
- להקפיד על כתיבה תקנית ותיעוד מתאים

## תכונות C++ שיש להדגים
1. **מרחבי שמות (Namespaces)** - שימוש במרחבי שמות `Geometry` ו-`Utils` להפרדת קוד
2. **מבנים (Structs)** - שימוש ב-structs לייצוג נקודה ומעגל
3. **פונקציות חופשיות (Free Functions)** - פונקציות שפועלות על המבנים
4. **קלט/פלט זרמים (Streams)** - שימוש ב-`iostream` לפלט (`cout`)
5. **הפרדה בין הצהרה למימוש** - שימוש נכון בקבצי `.hpp` ו-`.cpp`
6. **מערכים (Arrays)** - העברת מערכים לפונקציות
7. **טיפוסי נתונים (Data Types)** - שימוש ב-`double`, `int`, `bool`
8. **ספריות סטנדרטיות** - שימוש ב-`cmath` לחישובים מתמטיים
9. **בדיקות יחידה (Unit Testing)** - שימוש בספריית doctest לבדיקות

## קבצים במטלה

### קבצים שסופקו:
- **Point.hpp** - קובץ המכיל הגדרות למבנה נקודה ופונקציות לחישוב מרחק והדפסה
- **Circle.hpp** - קובץ המכיל הגדרות למבנה מעגל ופונקציות לחישוב שטח, היקף ובדיקת השתייכות נקודה
- **Utilities.hpp** - קובץ המכיל הצהרות לפונקציות עזר כמו מציאת נקודה הקרובה ביותר לראשית הצירים וחישוב ממוצע
- **main.cpp** - תוכנית ראשית המדגימה שימוש בכל הפונקציות עם הערות המציינות את הפלט הצפוי
- **test.cpp** - קובץ בדיקות 
- **doctest.h** - ספרייה לביצוע בדיקות אוטומטיות
- **Makefile** - קובץ לקימפול והרצה אוטומטית של הפרויקט

### קבצים שעליכם ליצור ולממש:
- **Point.cpp** - קובץ מימוש לפונקציות העוסקות בנקודות
- **Circle.cpp** - קובץ מימוש לפונקציות העוסקות במעגלים
- **Utilities.cpp** - קובץ מימוש לפונקציות העזר השונות 

## הוראות קימפול והרצה

### שימוש ב-Makefile:
הפרויקט כולל `Makefile` שמאפשר קימפול והרצה בקלות:

```bash
make        # מקמפל ומריץ את התוכנית הראשית
make test   # מקמפל ומריץ את בדיקות היחידה
make clean  # מנקה את כל קבצי הקימפול
```
